# Sova 콘솔용 보안 스냅샷 투영

상태: 로컬 구현·계약 검증. 실제 플랫폼 등록·배포·효과 영수증 연결은 미완료.

`adapters/console_workload.py`는 기존 `SecuritySnapshot`을 표시 문서로 바꾼다.
수집기, 정책 엔진, 승인 경로와 실행기를 추가하지 않는다. 원래의 Windows 인계 코드와
이미지 자격은 그대로 보존하며, 이 추가 모듈의 자격은 별도로 관리한다.

## 입력과 출력

호스트는 인증된 현재 계획에서 `ConsolePlanBinding`을 만든다. 입력은 테넌트·앱·계획
ID/digest/version·출발/목적지 환경이다. 브라우저가 이 값을 지정해 권한을 얻을 수 없다.

`project_security_snapshots(binding, snapshots, stream_id=..., revision=..., now=..., provenance=...)`
는 양쪽 환경 중 1~2개의 스냅샷을 받아 `console-workload.v1`을 반환한다.
`stream_id`와 단조 증가 revision은 호스트의 현재 생산자 기록에 결속해야 한다.

| 기존 자료 | 표시 결과 |
|---|---|
| SystemGraph 자원·관계 | 자원 종류·출발/목적지·등록된 의존성 |
| 현재 자원의 PostureFinding FAIL | 해당 자원의 구성 위반 경고 |
| PostureFinding PASS | 별도 실행/안전 완료 주장 없음 |
| 원래 observed_at/valid_until | 원래 시각 유지, 전체 표시 유효기간 최대 5분 |
| 자원 scope와 resource_revision | 안정적인 불투명 ID와 교체를 구별하는 revision ID |

자원 원문 이름, 인프라 주소, ARN, 로그, Secret·명령을 전달하지 않는다. 구성 수집의
`kubernetes_api` origin만 live 투영 후보가 될 수 있고, 저장된 그래프는 과거 관측,
`local_demo`는 합성으로만 표시한다. origin 문자열 자체가 인증은 아니다.

## 권한과 진실성의 경계

- 함수는 타입·범위·결속을 검사한다. 실제 생산자 인증·서명·테넌트 조회 권한은 호스트가 확인한다.
- 앱·환경이 다르거나 같은 환경이 중복되면 거부한다. 빈 그래프·48개 초과 자원·96개 초과 관계를 성공으로 축약하지 않는다.
- 동일 이름으로 자원이 교체돼도 이전 revision 근거를 빌리지 않는다.
- 구성 위반은 공격 확정이 아니다. 등록 관계는 실제 통신 관측이 아니다.
- `health`, 실제 연결 상태, 격리·대체·경로·복구 단계는 모두 미확인이다.
- 기존 SecurityEvent의 이름에 `verified`가 있다는 이유만으로 효과 완료를 만들지 않는다.
  실제 대응 표시에는 원장과 독립 readback을 확인하는 별도 공급자 연결이 필요하다.
- 출력의 `authorizes_execution`은 항상 false다. T10/T19나 기존 실행기의 승인 입력으로 쓰지 않는다.

## 소비 측 연결

플랫폼 콘솔의 `PlanWorkload`는 고정 producer ID·코드 SHA·원문 SHA-256, 현재 계획과
조회 권한, 생산자 인증을 읽기 전후에 확인한다. 브라우저는 같은 출처의 GET만 사용한다.
고정된 해시는 원문 변경을 찾는 수단이며 출처 인증을 대신하지 않는다.

생산자→소비자 교차 시험은 양쪽 10종 자원, 구성 위반 2건을 포함한다. Python 읽기 경계와
브라우저 표시 모델이 같은 JSON을 읽었고, 런타임 응답·격리·전환을 만들어 내지 않음을 확인했다.
이 시험은 합성 스냅샷이며 실제 클러스터 수집이나 운영 배포 시험이 아니다.

## 반영 전에 필요한 것

1. 등록된 실제 계획과 스냅샷 저장소를 읽는 호스트 경로 및 열람 권한을 확정한다.
2. 이 코드가 포함된 정확한 생산자 SHA/산출물에 대해 기존 검증 절차를 수행한다.
3. 새 생산자를 콘솔 호스트에 등록하고 실제 원문의 출처를 인증한다.
4. 현재 자원 UID, 지연/만료, 사용자·생산자 권한 회수와 다른 계획 접근 거부를 전용 창에서 확인한다.
5. 실제 격리·복구 표시는 기존 승인·효과 원장·독립 탐침과 연결한 뒤 별도로 인수한다.

기존 최종 이미지 `546f6e0`과 별도 90분 지속 시험 source `4511a43`에 이번 어댑터 결과를
합산하지 않는다. 이번 작업으로 운영 인수가 끝났다고 표시하지 않는다.
