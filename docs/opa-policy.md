# OPA 실행 전 정책 계약

보안 패키지는 Rego 평가기를 새로 구현하지 않는다. 운영자가 등록한 OPA 바이너리와 정책을 사용하며, OPA의 결과와 기존 Python 보안 검증을 모두 만족해야 실행을 허용한다. OPA의 허용 결과는 사용자 승인이나 실행 권한이 아니다.

## 등록과 승인

`OPAPolicy`는 앱 범위, 허용 자원, 필수 검증 의무, 목적, Rego 본문, 엔진 및 capabilities 해시, revision과 유효기간을 포함한다. 기본 목적은 일반 변경이며 별도로 등록한 마이그레이션 단계도 지원한다. 사고 대응·긴급 예외를 일반 정책으로 우회하지 않는다.

정책 전체 fingerprint로 만든 `policy.obligation`을 **승인 전** `LifecyclePlan.obligations`에 추가한다. 정책 변경은 계획 해시를 바꾸므로 기존 승인을 재사용할 수 없다. 실행 직전과 실행 중 기존 실행기가 호출하는 guard에 `OPAPlanPolicy.for_actor(actor)`를 조합한다. 기존 소유권·승인·보호 수준 guard를 대체하지 않는다.

필수 공급자는 인증된 현재 정책, 독립 검증 근거, 사용자 권한, 앱 보류 저장소와 신뢰할 수 있는 시계다. 브라우저나 에이전트의 JSON을 이 공급자의 신뢰된 결과로 사용하지 않는다. 활성 보류가 있으면 OPA를 실행하지 않고 차단한다. 평가 중 권한 회수, 근거·정책 변경, 보류 추가 또는 만료도 차단한다.

## 실행 경계

`PinnedLocalOPA`는 POSIX 운영자 소유 절대 경로 바이너리를 실행 전후 SHA-256으로 확인한다. 기본 평가 제한은 3초, 설정 가능한 상한은 10초다. 표준 출력은 64KiB, 오류 출력은 8KiB로 제한한다. 임시 파일은 비공개 디렉터리에 두며 클라우드 자격증명과 HOME 환경을 상속하지 않는다. 셸과 임의 쿼리는 사용하지 않는다.

고정 capabilities는 네트워크·런타임 환경·비결정적 시간 및 난수 built-in을 허용하지 않는다. 등록된 정책에 필요한 비교와 자료형 연산만 제공한다. 정책 오류, 미정의 결과, 중복·비정형 응답, 타임아웃은 실패로 처리한다. 원문 오류에 입력 비밀이 포함될 수 있으므로 호출자에게 그대로 전달하지 않는다.

이 경계는 **운영자 정책 평가**용이다. OS 수준 파일시스템·네트워크 샌드박스나 사용자 코드 실행 환경이 아니며 Harbor를 대신하지 않는다. 악성 운영자와 바이너리 경로에 대한 호스트 관리자 침해도 해결하지 않는다.

## 근거와 실행

`OPADecision`은 계획·정책·입력 해시와 판정, 사유 코드, 최대 30초의 유효기간을 기록한다. 기존 필수 통제가 PASS가 아니면 OPA가 허용하더라도 거부한다. 범위·목적·정책 바인딩도 Python에서 별도로 확인한다. 서명된 근거는 등록된 독립 검증기가 발급하며 최종 실행기는 기존 승인과 효과 원장을 사용한다.

## 검증 범위

- 공식 OPA 1.22.0의 고정 바이너리를 사용하는 통합 시험
- 허용·거부, 누락 필드, 변경된 정책·엔진·capabilities, 만료·보류·권한 회수
- 금지된 HTTP built-in을 포함한 정책이 실제 요청을 전송하지 못하는지 확인
- 프로세스 시간·출력 제한과 환경변수 비상속
- Sova 실행기와 독립 서명 검증을 조합한 시험: 기존 검증 실패 시 배포 어댑터를 호출하지 않음

CI는 Linux 바이너리 해시를 고정하고 Python 3.11·3.14에서 실행한다. 실제 고객 환경 정책 배포, 기업 인증 연결과 운영 배포 어댑터 자격은 별도다. 바이너리나 OPA 시험 환경이 없는 로컬 실행에서 skip된 시험을 통과로 집계하지 않는다.

공식 구현: [OPA 1.22.0](https://github.com/open-policy-agent/opa/releases/tag/v1.22.0). capabilities와 샘플 Rego, 공식 Apache 2.0 라이선스는 패키지 리소스에 포함한다.
